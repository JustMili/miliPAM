# Contributing

## Before you start
- Found a bug or have an idea? [Open an issue](../../issues/new) first so we can discuss it.
- **Security vulnerabilities:** do NOT open a public issue or PR. Report them privately (see SECURITY.md).

## Steps
**1. Fork the repository.**

**2. Create your branch for:**

- **features:** feature/branch-name
- **bugs:** bug/branch-name

**3. Commit your changes**

**4. Push to the branch**

**5. Open a Pull Request targeting the branch named `test`.**
