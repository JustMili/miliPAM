# Security Policy

## Reporting a vulnerability
Please do NOT open a public issue or pull request for security problems.

Report privately via GitHub:
[Report a vulnerability](https://github.com/JustMili/miliPAM/security/advisories/new)

Please include:
- a description of the problem and its impact
- steps to reproduce (or a proof of concept)
- affected version

Please give me reasonable time to fix the issue before disclosing it publicly.
